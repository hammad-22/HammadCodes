# Hammad Shahid | Windows 98 Edition 💾

Welcome to my portfolio! This isn't just a list of my work experience—it's a fully functional, interactive, and nostalgic trip back to 1998. Built from the ground up to mimic the classic Windows 98 aesthetic, this portfolio is designed to be explored. 

Take a look around, click on some icons, and see what you can find!

**🔗 [Live Demo](https://hammad.codes)**

---

## 💻 Cool Windows 98 Features

This portfolio is packed with interactive elements and Easter eggs to make exploring my resume a lot more fun:

- **Interactive Desktop Environment**: Draggable windows, minimize/maximize/close functionality, and a working taskbar.
- **The Start Menu**: Click the classic Start button to navigate through programs, documents, and settings.
- **Clippy is Here to Help!**: Everyone's favorite helpful (or annoying) paperclip assistant makes a comeback.
- **Fully Working Games**:
  - 💣 **Minesweeper**: A faithful recreation of the classic game.
  - 🐍 **Snake.exe**: A built-in terminal-style snake game.
- **Creative Applications**:
  - 🎨 **Paint**: Actually draw on the canvas using MS Paint.
  - 📝 **Notepad**: A fully functional text area to type random notes.
- **Customization**:
  - 🖥️ **Display Properties**: Change your desktop background color just like you could in Windows 98 (Teal, Black, Blue, Silver).
- **Easter Eggs & Surprises**:
  - 🗑️ **Recycle Bin**: Check what's been thrown away (including `my_social_life.txt` and `startup.wav`).
  - 💀 **System32**: Go ahead, click it. (Disclaimer: May cause a **Blue Screen of Death** 💥).

## 📂 What's Inside?

While you're enjoying the nostalgia, you can also learn more about my professional background:

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/hammad-22/HammadCodes.git
   ```
2. Navigate to the project directory:
   ```bash
   cd HammadCodes
   ```
3. Open `index.html` in your favorite web browser. No build steps or dependencies required!
